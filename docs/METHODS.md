# Experimental and analysis contracts

This document describes the earlier support-channel controls retained for
reproducibility. The current main claim concerns changing aggregation on fixed
ranked ballots; its methods are in the complete manuscript and latest replay
capsules. Do not substitute the earlier J contrast below for the current C or
selected-policy contrast.

## Scientific object

Allocation-conditioned use of proposal support in biomedical candidate selection. Homogeneous allocation H uses eight calls from the reference generator; mixed allocation M shares its first two calls and adds two calls from each of three other endpoints. The coupled policies therefore require 14 unique generation calls, not 16. Calls are matched; total tokens, cost and independent training replicas are not.

## Natural-pool support attachment

Candidates, rationale, display order and question are held fixed within each allocation. The true condition attaches each candidate's distinct proposing-call count and within-call best ranks. The shuffled condition reassigns complete support tuples. The LLM, frequency, reciprocal-rank, random and oracle rules are scored on the same pools. Tie-averaged and deterministic fixed-tie rules are retained separately. H and M natural pools differ in content, size and corruption dose: the original contrast is not an isolated causal effect of lineage identity.

Let D(method) be `(M_true - M_shuffled) - (H_true - H_shuffled)`. The focal natural contrast is `J = D(LLM) - D(frequency)`. It is not simply the accuracy gain from using more models. Fresh MedEinst confidence intervals resample the 96 case pairs, keeping branches and arms paired. Transport uses 128 items and stratification by medical task (43 diagnosis, 43 treatment, 42 basic science). Two primary selectors use 97.5% marginal bootstrap intervals. The common-pool experiment uses four designated primary intervals at 98.75%. Secondary and exploratory comparisons are labeled; all intervals condition on the chosen scoring map.

## Common-pool diagnostic

On the same 192 MedEinst branches and 128 MedXpertQA items, present one shared candidate universe without rationales. H- and M-derived ordinal support ranks are shown forward or reversed, plus a hidden-support reference. Each source has the same rank multiset and absolute reversal-displacement distribution; candidates and input token totals match for the four primary arms. Two candidate orders and two selectors give 6,400 choices. The normalized contrast is `J_norm = D(LLM) - D(top_rank)`. Changing both the interface and comparator means `J_norm` is not a rerun of the original J. Hidden-arm bytes match but token totals can differ by up to 49; the primary contrast excludes that arm.

## Boundaries and scoring

MedEinst criterion sensitivity distinguishes synonym identity from temporal, etiologic, severity/site and broader subtype credit. Those policies change the endpoint, not the observed generation. Unresolved relation labels remain a limitation; bootstrap uncertainty does not adjudicate them. MedXpertQA uses the official finite-option key, with no new semantic judge. All fixed cases remain in primary analyses, including failed generation slots. The model-subset/budget analysis is a post-hoc reuse of existing calls; it is not new independent evidence. Reused-case interventions, fresh-case confirmation and independent-source transport remain explicitly separate.

The exact source model identifiers and per-request hyperparameters are in the included schedules. Output caps, seeds, parsing and missingness remain visible. Scientific claims are bounded to the tested interfaces, tasks, criteria and endpoints; there is no patient-outcome or laboratory-loop validation.
